# Шпаргалка: создание статьи в блоге

## Frontmatter

```yaml
---
title: "Заголовок статьи"
excerpt: "Краткое описание — отображается на карточке и в meta description."
date: "2026-04-26"       # YYYY-MM-DD
tag: "Трудоустройство"   # произвольный текст, появится в фильтре
tagColor: "yellow"       # yellow | blue | green | purple | red
coverImage: "/blog/slug/cover.jpg"   # необязательно; .jpg или .png
---
```

### Цвета тегов

| tagColor | Цвет       |
|----------|------------|
| yellow   | Янтарный   |
| blue     | Синий      |
| green    | Изумрудный |
| purple   | Фиолетовый |
| red      | Розовый    |

---

## Обложка

Файл: `frontend/public/blog/<slug>/cover.jpg`  
В frontmatter: `coverImage: "/blog/<slug>/cover.jpg"`  
Рекомендуемый размер: **1200 × 630 px** (og:image).

---

## Markdown

```markdown
## Заголовок H2

### Заголовок H3

Обычный текст. **Жирный.** _Курсив._

- Маркированный список
- Пункт

1. Нумерованный список
2. Пункт

[Ссылка](https://example.com)

> Цитата — выделяется вертикальной чертой слева

`инлайн-код`

---
```

Горизонтальная линия `---` используется как разделитель перед финальной CTA-сноской.

---

## Картинки внутри статьи

```markdown
![Описание картинки](/blog/my-post-slug/image1.jpg)
```

Файлы кладутся рядом с обложкой: `frontend/public/blog/<slug>/image1.jpg`  
Стили (скругление, отступы, адаптивность) применяются автоматически.

---

## Структура файлов

```
frontend/
├── content/blog/
│   └── my-post-slug.md       ← статья
└── public/blog/
    └── my-post-slug/
        └── cover.jpg         ← обложка (необязательно)
```

Слаг = имя файла без `.md`. Только латиница, цифры, дефисы.  
Статьи сортируются по `date` убыванием — новые сверху.
